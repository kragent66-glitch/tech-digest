1Password Breach Traced to an Employee's GitHub Account - Account Records Copied, Vaults Untouched

1Password began investigating on November 19 after an attacker took over an employee's corporate GitHub account, used it to read private source and push malicious code into backend services, and pulled administrative records for a subset of customers. The data includes names, sign-in emails, account identifiers, creation and last sign-in times, public keys, SRP parameters, and tokens inside invitation, provisioning and account-recovery links. Vault contents were never reachable - 1Password does not hold users' secret keys. Private repos and the CI/CD system were also touched, so every credential that may have been exposed is being rotated. 1Password → | HN discussion →

OpenAI Says ω = 9/4 Exactly, With a Matching Lower Bound - Aaronson Calls It a Singularity for Hard Math

OpenAI's openai/math repository published preprints on November 24 arguing the matrix-multiplication exponent is exactly 9/4, with a lower bound matching the upper bound it posted on October 6 - closing a question open since Strassen showed ω<3 in the late 1960s. A second paper puts the linear-gate cost of the Fourier transform at N log^(1/2+o(1)) N, again with a matching lower bound, beating the FFT's O(N log N). Scott Aaronson wrote that he never expected any proof of ω>2, that Yupan Liu's QIP(2)=PSPACE preprint barely registered, and that P≠NP no longer feels distant. Shtetl-Optimized → | HN discussion →

Google's Cogentic Agent Solves Integer Factoring in L_N[1/3] - Six Papers, No Human Input

Google Research published six Cogentic papers on November 25, each generated by an agentic harness running Gemini 4 with no human interaction beyond the initial prompt. The headliners: unconditional integer factorisation in worst-case expected time L_N[1/3, 105] with L_N[1/3, 40] workspace and AKS-certified factors; discrete logs over fixed-characteristic finite fields in (pn)^(o(log n)); a polynomial-time 1/5-approximate Nash equilibrium for bimatrix games; and a break of the square-root barrier for the log-rank conjecture. Hidden Gems

zvec-ai/zvec-grep - Local Full-Text Search Built for Agents, Not Just Humans

zvec-grep is a local-first search layer over a working directory, aimed at the two consumers that now matter: a person typing at a prompt and an agent calling tools. The topics list BM25, CLI and code-search, which describes the shape of it - a persistent index rather than a grep loop, with an agent-facing surface alongside the command line. It has 4,382 stars at 4.6 months old, a velocity of roughly 960 stars a month, and was pushed today, so this is sustained development rather than a launch-week spike. GitHub

AhmadHassan-BTed/FormFilla - 1,015 Stars a Month Filling Job Applications Deterministically

FormFilla fills job-application forms from local JSON profile data and files, entirely inside the browser extension. The interesting decision is that matching is deterministic: multi-signal scoring, structural detection of repeated blocks such as education or employment rows, and bipartite optimisation to assign answers to fields - no LLM in the loop deciding what your notice period is. At 4,637 stars in 4.6 months, about 1,015 a month, it targets exactly the workload people most want automated and least want shipped to a server: the 40-field application form. GitHub

MODSetter/SurfSense - Air-Gapped NotebookLM for Documents You Cannot Upload

SurfSense is an air-gapped NotebookLM alternative: point it at confidential documents and it answers questions, generates flashcards and keeps the whole pipeline on your own machine, shipped as an Electron app. At 16,957 stars over 27.9 months it is the most established project in this list, still adding roughly 608 stars a month and pushed two days ago. The topics - document-ai, legal-ai, flashcards - name the audience precisely: people holding contracts, case files or research PDFs who will never accept a hosted RAG service. GitHub

cocoindex-io/cocoindex - Incremental Recompute Instead of Nightly Full Reindexing

Cocoindex describes itself as an incremental engine for long-horizon agents: define a dataflow from sources to derived artifacts and it recomputes only what changed, using change-data-capture rather than full rebuilds. That is the unglamorous bottleneck under most codebase and document agents - the reindex that runs for hours and invalidates itself halfway through. 11,939 stars across 20.8 months, about 574 a month, pushed today. Its topics, agentic-data-framework and codebase-intelligence, place it as infrastructure beneath agents rather than as another agent framework. GitHub

JerryZLiu/Dayflow - The Work Journal You Never Write, Assembled From Your Screen

Dayflow turns your screen into a private timeline of what you actually did, so the record exists without a timer you forget to start. It is local-first and open source, and its topics name ChatGPT, Claude, Gemini and LLM, which points at model calls summarising captured activity rather than the capture itself being shipped to a vendor. At 7,497 stars over 14.1 months it has held roughly 532 stars a month, with a push three days ago. The appeal is the artefact nobody produces by hand: an accurate account of where the day went. GitHub

VoltAgent/voltagent - A TypeScript Agent Framework With the Hosted Platform Attached

VoltAgent is a TypeScript framework plus platform for building AI agents, with agents, tools and workflows expressed in TypeScript rather than Python - which matters if the product already runs on Node and the agent has to live in the same process. 11,013 stars over 19.3 months is about 569 a month, though the last push was 20 days ago, the longest gap among the projects in this edition. The description calls it an AI agent engineering platform built on an open-source framework, so the OSS core is the entry point and the platform is the business. GitHub

0xsline/OpenChatCut - Conversational Video Editing With a Timeline You Can Still See

OpenChatCut is an open-source conversational video editor: local-first, with a real multi-track timeline, Agent Skills, MCP integration and Remotion rendering, so an agent can drive edits while the human still sees tracks, clips and cuts instead of a chat transcript. 3,337 stars in 4.4 months, roughly 758 a month. The CapCut comparison in its own topics is the tell - it is chasing the editor people already use, with the agent layer added on top, rather than a chat box that spits out a finished MP4 and takes the controls away. Graphicle-AI/graphicle - Code Graph and Agent Memory in One Rust Binary

Graphicle packs a code graph and agent memory into a single Rust program, exposed over MCP to Claude Code, Codex, Cursor or any other MCP client. 623 stars in 1.4 months - about 441 a month - makes it the youngest project in this edition, and the Rust-plus-code-graph combination suggests the goal is answering structural questions, such as who calls this and what breaks, without shipping the repository as context. One binary to install for structure and memory, rather than two services to keep running. GitHub

hello245m/free-stockdb - Local A-Share Quant Engine Where the Data Plumbing Is a File You Own

Free-stockdb is a local quantitative engine for China's A-share market: daily and minute K-line data plus ETF minute bars, with incremental synchronisation, a local cache, split and dividend adjustment, batch queries, backtesting and indicator computation. 3,202 stars in 6.6 months, about 483 a month, last pushed 15 days ago. The value is mundane and real - most backtests die on data plumbing, and this turns the plumbing into a local file you own instead of an API quota someone else controls. GitHub

Lean and Differential Testing Found 17 Unreported Bugs in Clojure's Core

Conao3 modelled small pieces of Clojure's Java core in Lean 4, used bv_decide to hunt counterexamples, and differential-tested the persistent collections against java.util - surfacing 17 bugs that are absent from Clojure's JIRA and ask.clojure.org. The best one: (reduce + (drop 1 (into (vector-of :long) (range 65505)))) never returns, because a 0xffe0 mask added in 2010 clears bit 16 and sends reduce back to index zero forever. There is also a HAMT dissoc that stores the caller's hash, leaving a key visible in the printed map but unlookupable. Tested on Clojure 1.12.7, JDK 21. Conao3 Notes → | HN discussion →

The Polynomial Hirsch Conjecture Is False, Per an OpenAI Preprint

An OpenAI preprint dated November 24 constructs simple polytopes whose graph diameter is superpolynomial in the number of facets, which would make the polynomial Hirsch conjecture false - the claim that a d-dimensional polytope with n facets has an edge graph of diameter polynomial in n and d. The file sits in the same openai/math repository that has been dropping complexity and geometry results all week, alongside Lean formalisations. If it holds, one of the standard routes for bounding simplex-method pivot counts is closed, and the diameter question reopens for the first time in decades. Preprint → | HN discussion →

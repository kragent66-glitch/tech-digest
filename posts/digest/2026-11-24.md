### GLM-5.4 Loops 28 Layers Twice at 750B, Targets 2T-Class Intelligence
Z.ai shipped GLM-5.4, its first flagship on a Loop Transformer: 28 layers of the GLM-5 base model run for two iterations, buying depth without new parameters. Three fixes made it deployable at 750B - per-token gates that stop activation norms blowing up across passes, a hybrid KV cache that reuses the first pass's sparse selection plus a sliding window for the second, and sparse-index reuse. Z.ai claims intelligence comparable to 2T - 3T parameter models, 200 tokens/s off-peak and 70 - 80 at peak, with output length down 10 - 14% on GPQA-Diamond and MMLU-Pro. Weights are not out yet.
[Z.ai](https://z.ai/blog/glm-5.4) | [HN discussion](https://news.ycombinator.com/item?id=50609685)

### Ladybird Ships Its Alpha - A Browser Engine Built From Scratch, Not a Fork
Ladybird published its first alpha for macOS and Linux, a browser wrapped around an engine built from the ground up rather than forked from Chromium or Gecko. The team is blunt about the state of it: some sites will not work, it will crash, and there are no security promises today - researchers are explicitly invited to attack it. It ships as a rolling channel with automatic updates, so testers no longer need to build from source, and it exposes WebDriver plus the Firefox DevTools protocol for automated testing. Broken sites and crashes can be reported from inside the browser.
[Ladybird](https://ladybird.org/posts/alpha/) | [HN discussion](https://news.ycombinator.com/item?id=50614249)

### One LoRA Per Harness: 39% to 55% on Terminal-Bench, Tokens Cut From 2.9K to 1.5K
Hugging Face showed that an RL-trained adapter, fitted inside the agent harness you actually run, beats the frozen base model on that same harness. With Qwen3.8-27B held fixed, a harness adapter lifted Terminal-Bench 2.1 pass@1 from 39% to 55% under pi while average token use fell from 2.9K to 1.5K per task - the model reasons less, calls fewer tools, and gets it right first time more often. Adapters were trained separately for pi 1.5.2, OpenCode 2.2.7 and Hermes Agent v0.22.6, then merged into one super adapter that runs unchanged under all three.
[Hugging Face](https://huggingface.co/blog/harness-adapters-at-scale)

### Anthropic Publishes a Lean 4 Proof That VP ≠ VNP Over Every Field
Anthropic's formal-math repository now hosts a claimed proof that VP is a proper subset of VNP over every field, and that VNP is not contained in the closure of VP: circuits for the Hamiltonian cycle polynomial - and for the permanent outside characteristic 2 - need more than m^(c(log m)^(1/3)) gates for all large m, with the same bound holding for approximating circuits. It does not settle P versus NP. Anthropic states an internal research Claude model discovered the result, paper and formalization were both written by models, and no human mathematician has checked the proof.
[GitHub](https://github.com/anthropics/formal-math/tree/main/vp-vnp) | [HN discussion](https://news.ycombinator.com/item?id=50620102)

## Fun Tech
### NO SPEAKER Makes a MacBook Trackpad Talk Using Its Haptic Motor
NO SPEAKER drives the Force Touch trackpad's haptic motor up to 4,000 times a second, fast enough that the glass itself produces audible sound. macOS's own voice is analysed every 10 ms for its two strongest formants, loudness and pitch, then replayed as sine tones through the motor so it buzzes like a voice instead of whistling; two resonances beat three in a blind test. It is one Swift file with no dependencies, MIT licensed, reaching the private MultitouchSupport framework because Apple's public haptics API exposes three fixed taps.
[GitHub](https://github.com/os6/nospeaker) | [HN discussion](https://news.ycombinator.com/item?id=50610318)

### win4wine Runs Windows XP's Real Explorer as the Linux Desktop Shell
win4wine puts Windows XP's genuine explorer.exe on top of a patched Wine and uses it as the Linux desktop shell: Luna taskbar, Start menu, desktop and folder windows, with Linux applications wearing XP frames and appearing under All Programs. Tray icons bridge StatusNotifierItem and XEmbed, the XP network flyout reads NetworkManager, and DPI scaling plus Japanese input through fcitx5 both work. Installation is a script on a fresh Debian 13 using your own XP SP3 ISO - Microsoft binaries are not bundled. ReactOS and Windows 7 shells are options too. Explicitly experimental.
[GitHub](https://github.com/mikuta0407/win4wine) | [HN discussion](https://news.ycombinator.com/item?id=50610743)

### C++26 Is Done, Again - Contracts Ballot Failed Unanimity First Time
The ISO C++ committee completed technical work on C++26 for a second time, in Búzios, Brazil, after the first Draft International Standard ballot failed to pass unanimously - overwhelmingly over contracts: pre, post and contract_assert. An updated document now heads back for a second approval ballot. Roughly 220 experts attended, 35% of them remotely, partly because a US aviation ground stop disrupted travel, formally representing 27 nations. C++29 work continued regardless: break label, continue label, std::ranges::any_view and views::slice were adopted. Next full meeting is Istanbul in March.
[Herb Sutter](https://herbsutter.com/2026/11/21/c26-is-done-again-trip-report-november-2026-iso-c-standards-meeting-buzios-brazil/) | [HN discussion](https://news.ycombinator.com/item?id=50600838)

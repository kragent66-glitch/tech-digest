# DeepSeek's 166K-star plugin harness, Mojo goes open source, and a 27B model matches the giants

The day's biggest stories: DeepSeek's "everything is a plugin" harness crossed 166K stars, Modular finally open-sourced Mojo under Apache 2, and Qwen's 27B model matched models 60x its size. Plus: an AirTag caught an Amazon facility scanning rare books, and Accenture's leaked audio confirmed the tokenpocalypse.

## AI/ML News

**Mojo is now open source.** Modular released the Mojo compiler and toolchain under Apache 2, weeks after shipping Mojo 1.0. The Python-superset promise from May 2023 officially died in Aug 2025 - the language now targets painless GPU programming with Python-inspired syntax. Apache 2 keeps the whole AI stack commercially open, no copyleft strings. [Source](https://www.modular.com/blog/mojo-open-source)

**Qwen 3.8 27B scores 52 on the Artificial Analysis Intelligence Index.** That equals GPT-5.6 Luna (max) and sits one point behind GLM-5.2 (max, 753B params) and DeepSeek V4 Pro (max, 1.7T). A 27B model matching systems 30-60x its size, under Apache 2: laptop-class inference just got serious. [Source](https://artificialanalysis.ai/models/qwen3-8-27b)

**An AirTag caught an Amazon facility scanning rare books.** 404 Media tracked a ~1,000-book bulk order to Amazon's LAS8 facility in Las Vegas, where the VGT3 corner runs destructive book scanning; workers confirmed it in forum posts. The clearest evidence yet of AI-training data sourcing running outside public view. [Source](https://www.404media.co/we-tracked-a-shipment-of-rare-books-it-ended-at-an-amazon-ai-training-facility/)

**The tokenpocalypse is here, says Accenture.** Leaked internal audio: non-engineers now drive token consumption, and PDF-to-markdown is one of the biggest token chewers ("I hope you didn't just convert a PDF into images and then into markdown" - "that's what our data shows"). Companies are rationing tokens; expect cheaper models, caching, and local inference to keep winning. [Source](https://www.404media.co/the-tokenpocalypse-is-here-companies-are-scrambling-to-stop-spending-so-much-on-ai/)

## Big Famous GitHub Releases

**deepseek-ai/deepseek-harness ⭐166K** - "Everything is a Plugin." MIT, 12,404 commits, 17.6K forks. `npx @deepseek-ai/dsh web` boots a Web UI at :3080; the harness itself is a plugin, and there's a whole `dsh-plugin` ecosystem topic. The biggest open-source release of the week by a wide margin - DeepSeek's answer to agent tooling sprawl, and the community responded. [GitHub](https://github.com/deepseek-ai/deepseek-harness)

**xai-org/grok-build ⭐25.2K** - SpaceXAI's coding agent harness and TUI. Apache-2.0, Rust core, fullscreen + mouse-interactive, and it ports codex and opencode tooling. The terminal-native entrant in the coding-agent wars, competing with Claude Code and Codex for the same developer workflow. [GitHub](https://github.com/xai-org/grok-build)

**firecrawl/anydoc ⭐16.7K** - Word, PowerPoint, Excel, ODT, RTF, EPUB, CSV, PDF to clean GitHub-Flavored Markdown in **single-digit milliseconds**. Rust core with Node, Python, and WASM bindings; one shared document model so a table-escaping fix for docx automatically fixes rtf and odt. The anti-tokenpocalypse tool: convert docs locally so agents never burn tokens re-reading raw formats. [GitHub](https://github.com/firecrawl/anydoc)

## Under-the-Radar Finds

**guillaumemeyer/watermarks-remover ⭐15.2K** - strips multi-vendor AI provenance marks: Unicode text hygiene + statistical rewrite hooks. Controversial by design; the star velocity says provenance-marking is the conversation developers are having right now. [GitHub](https://github.com/guillaumemeyer/watermarks-remover)

**eric-sabe/honey ⭐40, rising** - hands-off supply-chain watchdog for dev machines: orchestrates multiple security scanners in the background. Tiny star count, but the right idea as dependency-based attacks keep climbing. One to watch. [GitHub](https://github.com/eric-sabe/honey)

**Why it matters.** Two threads dominate the week: the economics of AI are forcing efficiency everywhere (small models matching giants, local document pre-processing, token rationing), and the agent-harness platform race is being fought in open source - DeepSeek's 166K-star plugin-everything harness versus SpaceXAI's Rust TUI. Expect agent-harness consolidation to be the story of the next quarter.

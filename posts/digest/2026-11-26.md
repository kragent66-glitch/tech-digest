### 1Password Breach Traced to an Employee's GitHub Account - Account Records Copied, Vaults Untouched
1Password began investigating on November 19 after an attacker took over an employee's corporate GitHub account, used it to read private source and push malicious code into backend services, and pulled administrative records for a subset of customers. The data includes names, sign-in emails, account identifiers, creation and last sign-in times, public keys, SRP parameters, and tokens inside invitation, provisioning and account-recovery links. Vault contents were never reachable - 1Password does not hold users' secret keys. Private repos and the CI/CD system were also touched, so every credential that may have been exposed is being rotated.

### OpenAI Says ω = 9/4 Exactly, With a Matching Lower Bound - Aaronson Calls It a Singularity for Hard Math
OpenAI's openai/math repository published preprints on November 24 arguing the matrix-multiplication exponent is exactly 9/4, with a lower bound matching the upper bound it posted on October 6 - closing a question open since Strassen showed ω<3 in the late 1960s. A second paper puts the linear-gate cost of the Fourier transform at N log^(1/2+o(1)) N, again with a matching lower bound, beating the FFT's O(N log N). Scott Aaronson wrote that he never expected any proof of ω>2, that Yupan Liu's QIP(2)=PSPACE preprint barely registered, and that P≠NP no longer feels distant.
[Shtetl-Optimized →](https://scottaaronson.blog/?p=10379) | [HN discussion →](https://news.ycombinator.com/item?id=50646108)

### Google's Cogentic Agent Solves Integer Factoring in L_N[1/3] - Six Papers, No Human Input
Google Research published six Cogentic papers on November 25, each generated by an agentic harness running Gemini 4 with no human interaction beyond the initial prompt. The headliners: unconditional integer factorisation in worst-case expected time L_N[1/3, 105] with L_N[1/3, 40] workspace and AKS-certified factors; discrete logs over fixed-characteristic finite fields in (pn)^(o(log n)); a polynomial-time 1/5-approximate Nash equilibrium for bimatrix games; and a break of the square-root barrier for the log-rank conjecture. Each paper claims a Mathlib-only Lean 4 v4.35.0 formalisation, due as a companion release.

### Latency Fingerprinting Says TypeSafe's Jev Is Probably Qwen3.5-35B-A3B

### AhmadHassan-BTed/FormFilla - 1,015 Stars a Month Filling Job Applications Deterministically
FormFilla fills job-application forms from local JSON profile data and files, entirely inside the browser extension. The interesting decision is that matching is deterministic: multi-signal scoring, structural detection of repeated blocks such as education or employment rows, and bipartite optimisation to assign answers to fields - no LLM in the loop deciding what your notice period is. At 4,637 stars in 4.6 months, about 1,015 a month, it targets exactly the workload people most want automated and least want shipped to a server: the 40-field application form.
[GitHub](https://github.com/AhmadHassan-BTed/FormFilla)

### Lean and Differential Testing Found 17 Unreported Bugs in Clojure's Core
Conao3 modelled small pieces of Clojure's Java core in Lean 4, used bv_decide to hunt counterexamples, and differential-tested the persistent collections against java.util - surfacing 17 bugs that are absent from Clojure's JIRA and ask.clojure.org. The best one: (reduce + (drop 1 (into (vector-of :long) (range 65505)))) never returns, because a 0xffe0 mask added in 2010 clears bit 16 and sends reduce back to index zero forever. There is also a HAMT dissoc that stores the caller's hash, leaving a key visible in the printed map but unlookupable. Tested on Clojure 1.12.7, JDK 21.

### The Polynomial Hirsch Conjecture Is False, Per an OpenAI Preprint
An OpenAI preprint dated November 24 constructs simple polytopes whose graph diameter is superpolynomial in the number of facets, which would make the polynomial Hirsch conjecture false - the claim that a d-dimensional polytope with n facets has an edge graph of diameter polynomial in n and d. The file sits in the same openai/math repository that has been dropping complexity and geometry results all week, alongside Lean formalisations. If it holds, one of the standard routes for bounding simplex-method pivot counts is closed, and the diameter question reopens for the first time in decades.

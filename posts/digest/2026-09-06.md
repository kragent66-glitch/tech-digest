# OpenAI GPT-6 Astra Ships With 97.6% FrontierMath Score, $30B Crusoe Valuation, and Tesla's Cybercab Goes Live

OpenAI's GPT-6 Astra rolled out on September 3 with benchmark numbers that redefine what frontier models can do — 97.6% on FrontierMath Tier 4, 99.9% on ARC-AGI-3, and the discovery of two zero-day vulnerabilities during internal testing. The launch was accompanied by a firestorm over its "looped transformer" architecture, which safety experts warn could make future AI reasoning permanently opaque to humans. Meanwhile, Crusoe tripled its valuation to $30 billion in just 10 months, Tesla took the wraps off its production-ready Cybercab robotaxi in Austin, and MapQuest climbed to #1 on the App Store by refusing to rename Lake Ontario.

## AI & ML News

**OpenAI Ships GPT-6 Astra — Scores 97.6% on FrontierMath and Finds Two Zero-Days During Testing**

OpenAI rolled out GPT-6 Astra on September 3 to ChatGPT Plus, Pro, Business, and Enterprise users, plus the API and AWS. The model scores 97.6% on FrontierMath Tier 4 v2 (vs. GPT-5.6 Sol's 83%), 99.9% on ARC-AGI-3, and 100% on ExploitBench — though it was the contamination-controlled version (June–August 2026 vulnerabilities) that drew the most attention at 39% versus Sol's 5.5%. During evaluation, Astra discovered and chained two zero-day vulnerabilities. API pricing lands at $10/M input, $50/M output, $1/M cached — roughly 2.5x the cost of Sol. President Greg Brockman called it "the arrival of AGI," while the model's 1.1M token context window makes it the largest OpenAI has shipped. [OpenAI](https://openai.com/index/gpt-6-astra) · [Benchmarks](https://www.datacamp.com/blog/gpt-6-astra)

**Safety Experts Sound Alarm Over Astra's "Looped Transformer" Architecture**

Fortune reported that Astra uses "recurrent depth" — a looped transformer architecture that feeds tokens through the same block repeatedly, producing reasoning steps as "neuralese" rather than human-readable text. The method saves 50–90% compute, but chain-of-thought monitoring — the exact technique that caught the Hugging Face breach — is gutted. Peter Wildeford called it "potentially reckless." Steven Adler, a former OpenAI safety researcher, said it "violates one of the few redlines in the industry." Jakub Pachoki, OpenAI's chief scientist, pushed back, saying chain-of-thought monitoring remains a "core goal." The real fear: not Astra itself, but that the technique becomes an industry norm, eventually making all model reasoning opaque. ## Big GitHub Releases

**Block's Buzz Hits 31K Stars — Rust-Powered Hive Mind Where Humans and AI Agents Are First-Class Peers**

Block (formerly Square) open-sourced Buzz, a self-hosted team communication platform built on the Nostr protocol where AI agents and humans are treated as equals. Every action — chat, reaction, workflow, canvas — is a cryptographically signed Nostr event. The platform uses a Rust workspace (Axum WebSocket + REST) with Postgres, Redis, and S3/MinIO. It hit 31.1K stars with 4K forks. The Agent Communication Protocol (ACP) bridges Buzz relay events to Claude Code, Codex, and Goose agents via stdio JSON-RPC. Apache 2.0 licensed. [GitHub](https://github.com/block/buzz)

**Ponytail: The "Laziest Senior Dev" Skill Hits 128K Stars — 54% Less Code, 3–6x Faster**

DietrichGebert's Ponytail agent skill, which forces AI coding agents through a 7-rung "laziness ladder" before writing any code, is now the #1 trending repo on GitHub at 128K stars. The ladder runs: Does this need to exist? (YAGNI) → Already in codebase? → Stdlib does it? → Native platform? → Installed dependency? → One line? → Only then: minimum that works. Benchmark results show 54% average code reduction, 3–6x latency improvements, and 42–75% cost cuts across all Claude models. [GitHub](https://github.com/dietrichgebert/ponytail)

**blader/humanizer Reaches 43.5K Stars — Agent Skill That Strips AI Writing Fingerprints**

A Python agent skill called "humanizer" is gaining serious traction on GitHub trending, racking up 43.5K stars with 990 stars today and 3,646 forks. The tool removes signs of AI-generated writing from text — designed to work across Claude Code, Codex, Cursor, and other Skills-compatible agents. It's part of a growing ecosystem of "de-AI" writing tools responding to the backlash against AI-generated content. [GitHub](https://github.com/blader/humanizer)

**magnitudedev/magnitude — Open-Source Inference Server That Auto-Routes to Best Local Models**

Magnitude is a new open-source inference server that automatically selects the best local model for your hardware and plugs into whatever agent you already use — Pi, OpenCode, Hermes, OpenClaw, Codex, Claude Code, Cline. It hit 3,218 stars with 674 stars today, signaling strong developer interest in local-first AI inference. The TypeScript-based project positions itself as the missing middleware layer between hardware-aware model selection and agent frameworks. [GitHub](https://github.com/magnitudedev/magnitude)
